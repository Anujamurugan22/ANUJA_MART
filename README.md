ANUJA MART

Online Shopping Web Application

ANUJA MART is a Java-based online shopping web application that allows buyers to browse and purchase products from multiple sellers.

Features

Buyer Module

- Buyer registration and login
- View products
- Search and category filtering
- Add products to cart
- Update and remove cart items
- Checkout
- Order history
- Product ratings and reviews

Seller Module

- Seller registration and login
- Add products
- Edit products
- Delete products
- View received orders

Admin Module

- Admin login
- Manage users
- Manage products
- Manage orders

Order Module

- Confirm orders
- Track order status
- View order history

Review Module

- Product ratings
- Product comments

AI Chatbot

- Provides shopping assistance to users

Technologies Used

- Java
- Java Servlets
- JSP
- HTML/CSS
- JDBC
- MySQL
- Apache Tomcat 9
- Maven
- GitHub

Purpose

The main purpose of ANUJA MART is to provide a simple and user-friendly online shopping platform with separate functionalities for buyers, sellers and administrators
